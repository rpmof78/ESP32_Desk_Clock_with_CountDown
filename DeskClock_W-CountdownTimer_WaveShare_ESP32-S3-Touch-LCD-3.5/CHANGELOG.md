# Changelog

All notable changes to this project will be documented in this file.

## Version 1.0

Initial public release.

### Included

- Desk clock display
- Countdown timer
- Days Remaining display
- Touch and button navigation
- Wi-Fi configuration
- Web-based configuration interface
- Configurable hostname
- Background image selection and rotation
- Speaker controls and alert audio
- Battery, USB power, ambient light, and system temperature monitoring
- Automatic display brightness control
- Event and battery logging to microSD
- Setup Mode recovery/configuration
