# Background Image Guidelines

Background images for the Desk Countdown Clock are stored in this folder:

```text
/backgrounds/
```

## Preferred image format

- JPEG / JPG
- Baseline JPEG preferred
- 24-bit color
- Landscape orientation

## Preferred image size

The display resolution is **480 × 320 pixels** with a **3:2 aspect ratio**.

For the best appearance and fastest loading, prepare background images at exactly:

```text
480 × 320 pixels
```

Using images already sized for the display avoids unnecessary scaling and gives predictable framing.

## Image content recommendations

The clock, countdown, date, status information, and footer are drawn over the selected background. Images work best when they:

- have moderate overall contrast;
- avoid very bright highlights behind text areas;
- avoid excessive fine detail or visual clutter;
- contain relatively calm areas where the clock and countdown text are displayed;
- are cropped specifically for the 480 × 320 landscape display.

Scenic photographs and simple photographic backgrounds generally work well.

## File size

Smaller JPEG files reduce SD-card load time and web-preview transfer time.

Recommended targets:

- **Under 300 KB preferred**
- **Under 500 KB acceptable**

Use reasonable JPEG compression while preserving acceptable visual quality.

## File names

Use simple file names containing letters, numbers, underscores, or hyphens.

Examples:

```text
Autum_River.jpg
Beach_Sunset.jpg
Old_Barn.jpg
```

Avoid unusual punctuation or excessively long file names.

## Adding backgrounds

1. Prepare the image using the criteria above.
2. Copy the `.jpg` or `.jpeg` file into `/backgrounds/` on the microSD card.
3. Insert the card and start the clock.
4. Select the image from the web interface background controls.

Background images may also participate in timed background rotation when that feature is enabled.

## Troubleshooting

If a background appears poorly framed, overly bright, difficult to read, or slow to load, resize and crop it to **480 × 320** and reduce the JPEG file size before trying it again.
